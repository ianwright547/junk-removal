# Job photos

Upload your photos here named exactly:

job-1, job-2, job-3 ... up to job-12

Any common format works: .jpg, .jpeg, .png, .webp, .avif (upper or lower case).
HEIC from an iPhone does NOT work — convert to JPG first.

They show up automatically in the "Recent jobs" section. If there are no photos,
the section stays hidden.

Keep each photo under ~500 KB (resize to ~1600px wide) so the site stays fast.
